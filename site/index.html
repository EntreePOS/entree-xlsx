Beginner · 3 minutes

I need to export database records

Feature Workbook creation and record export

Use this when: Your application has an array of records and a user needs a normal Excel file they can open, filter, and share.

Code: create-inventory.js
import { createWorkbook } from "@entree_pos/xlsx";

const workbook = createWorkbook("Inventory");
const sheet = workbook.sheet();

sheet.replaceData([
  { sku: "BK-101", item: "Burger", stock: 34 },
  { sku: "FR-204", item: "Fries", stock: 18 },
  { sku: "DR-305", item: "Cold Brew", stock: 27 },
  { sku: "DS-410", item: "Cake", stock: 9 }
]);

sheet.autoFit({ min: 12, max: 28, padding: 3 });
await workbook.save("inventory.xlsx");

Be aware

Object keys become column headers in insertion order. Normalize records first if different rows can contain different keys.

Show advanced tip

Return the workbook from an API

Use toBuffer() when returning a file from an HTTP route, or toBase64() when another service expects text.

Beginner · 6 minutes

I need every report to use the same styles

Feature Named and reusable workbook styles

Use this when: Several reports need the same headers, currency formats, status colors, and brand treatment.

Code: styles.js
workbook.styles
  .define("money", {
    numberFormat: "$#,##0.00;[Red]-$#,##0.00"
  })
  .define("success", {
    bold: true,
    color: "#2E7D5B",
    fill: "#E6F4ED",
    horizontal: "center"
  });

sheet.cell("C6").style("money");
sheet.cell("C7").style("success");

sheet.range("A4:D4").style({
  bold: true,
  color: "#FFFFFF",
  fill: "#2457C5"
});

Be aware

Excel stores style records globally. Named styles keep large workbooks smaller and make visual changes easier to maintain.

Show advanced tip

Compose and copy styles

Style ranges with inside and outline borders, copy styles between cells, or clear selected properties without changing values.

Intermediate · 7 minutes

I need invoice totals to calculate in Excel

Feature Formulas, cached values, and number formats

Use this when: You are generating an invoice, budget, or report whose totals must update when someone edits the spreadsheet.

Code: invoice-totals.js
sheet.range("A4:D7").setValues([
  ["Item", "Quantity", "Price", "Total"],
  ["Classic Burger", 2, 12.5, null],
  ["Seasoned Fries", 1, 4, null],
  ["Cold Brew", 2, 3.5, null]
]);

sheet.cell("D5").formula("B5*C5", 25);
sheet.cell("D6").formula("B6*C6", 4);
sheet.cell("D7").formula("B7*C7", 7);
sheet.cell("D8").formula("SUM(D5:D7)", 36);

sheet.range("C5:D8").style({
  numberFormat: "$#,##0.00"
});

Be aware

The second argument to formula() is the cached value shown by previewers that do not calculate formulas. Excel recalculates the formula when opened.

Show advanced tip

Control calculated cells

Combine formulas with locked styles and worksheet protection to create controlled calculation models.

Intermediate · 8 minutes

I need an order report staff can filter

Feature Layout, filters, merged cells, widths, and links

Use this when: A raw export is technically correct but staff need a readable daily report with filters and links back to your application.

Code: order-report.js
sheet.range("A1:E1").merge();
sheet.cell("A1").set("Open orders").style({
  bold: true,
  fontSize: 18,
  color: "#FFFFFF",
  fill: "#17202A"
});

sheet.autoFilter("A4:E9");
sheet.setColumnWidth("B", 22);
sheet.setColumnWidth("E", 18);

sheet.cell("E5")
  .set("Open order")
  .hyperlink(
    "https://example.com/orders/1041",
    "View order details"
  );

Be aware

hyperlink() adds the destination and tooltip. Set the visible cell label separately so every spreadsheet viewer shows useful text.

Show advanced tip

Balance automatic and fixed widths

Use autoFit() for unknown data, then override important columns with explicit widths to keep reports predictable.

Intermediate · 9 minutes

I need to fill an existing invoice template

Feature Lossless XLSX and XLSM template editing

Use this when: A designer or accountant already owns the workbook layout and your code only needs to insert current data.

Code: fill-template.js
import { openWorkbook } from "@entree_pos/xlsx";

const workbook = await openWorkbook(
  "invoice-template.xlsx"
);
const sheet = workbook.sheet("Invoice");

sheet.range("A5:C7").setValues([
  ["Lunch catering", 12, 18.5],
  ["Coffee service", 12, 3.25],
  ["Delivery", 1, 25]
]);

sheet.cell("D5").formula("B5*C5", 222);
sheet.cell("D6").formula("B6*C6", 39);
sheet.cell("D7").formula("B7*C7", 25);
sheet.cell("D8").formula("SUM(D5:D7)", 286);

await workbook.save("invoice-ready.xlsx");

Be aware

Open the final file in the desktop app your customers use. Complex templates can contain macros, controls, or vendor-specific extensions.

Show advanced tip

Preserve complex workbook parts

The library patches changed OOXML parts and preserves untouched images, VBA, form controls, and unknown extensions in XLSX and XLSM files.

Advanced · 10 minutes

I need to add a revenue chart

Feature Native Excel chart creation and editing

Use this when: A report contains monthly or categorical values and readers need to recognize a trend without scanning every number.

Code: revenue-chart.js
const chart = workbook.charts.add("Sales", {
  name: "RevenueTrend",
  type: "line",
  title: "Revenue trend",
  range: "A4:B9",
  position: { from: "D4", to: "K18" },
  legend: false
});

// Change it later without rebuilding the chart.
workbook.charts.update(chart.id, {
  type: "column",
  title: "Monthly revenue"
});

Be aware

The source range needs a header row and numeric values. Choose a chart type that matches the question, not just the shape of the data.

Show advanced tip

Edit charts after creation

Column, bar, line, pie, and scatter charts are supported. List existing charts, update them by ID, or remove them from a template.

Advanced · 12 minutes

I need to summarize sales by region

Feature Native Excel PivotTable creation

Use this when: Many source rows need to be grouped by region, category, store, or another dimension that Excel users may explore.

Code: sales-pivot.js
workbook.addSheet("Summary");

const pivot = workbook.pivots.add({
  name: "SalesByRegion",
  source: {
    sheet: "Orders",
    range: "A1:C7"
  },
  target: {
    sheet: "Summary",
    cell: "A4"
  },
  rows: ["region"],
  columns: ["category"],
  values: [
    { field: "sales", summarize: "sum", name: "Total sales" }
  ]
});

Be aware

PivotTables rely on stable source headers. Excel refreshes the native pivot on open; lightweight preview tools may show only its cached values.

Show advanced tip

Change the analysis

Add filters, change row and column fields, or summarize with sum, count, average, minimum, and maximum.

Advanced · 10 minutes

I need to secure a private report

Feature Cell protection, workbook protection, and file encryption

Use this when: Users may edit input cells but formulas and workbook structure must stay locked, or the file itself contains private data.

Code: private-report.js
// Let users edit only the input cells.
sheet.range("A5:C6").style({
  fill: "#FFF2D8",
  protection: { locked: false }
});

sheet.protect({
  password: process.env.SHEET_PASSWORD,
  selectUnlockedCells: true
});

workbook.protect({
  password: process.env.STRUCTURE_PASSWORD,
  structure: true
});

await workbook.save("private-report.xlsx", {
  password: process.env.FILE_PASSWORD
});

Be aware

Worksheet and workbook protection discourage edits. File encryption protects the file contents. Use environment variables or a secret manager for real passwords.

Show advanced tip

Reopen encrypted workbooks

Encrypted files use Excel-compatible AES-256 Agile Office encryption and can be reopened with openWorkbook(path, { password }).
